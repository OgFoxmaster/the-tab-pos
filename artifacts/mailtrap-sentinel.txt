=== SMTP DIAGNOSTICS ===
If forgot-password is failing with:
  "Password reset email delivery failed. The API is configured, but Mailtrap SMTP authentication failed."

then the API is configured and the failure is Mailtrap SMTP rejecting the attempt.
Likely causes:
1. MAILTRAP_API_TOKEN is wrong/invalid.
2. MAILTRAP_FROM is not a verified sender.
3. Sender domain is not verified in Mailtrap.
4. Sending is not enabled for the account/environment.

Check Mailtrap Email Logs:
- https://mailtrap.io/sending/email_logs
